
# 📊 Task 8: Simple Sales Dashboard

## 🧾 Overview
This project involves creating an interactive sales dashboard using Tableau to analyze performance based on Region, Category, and Time using the provided sales dataset (`train.csv`).

---

## 🛠 Tools Used
- Tableau Public
- Python (for data inspection)
- Excel/CSV Dataset

---

## 📈 Visuals Included
1. **Line Chart**: Sales Over Time (Month-Year)
2. **Bar Chart**: Sales by Region
3. **Horizontal Bar Chart**: Sales by Sub-Category
4. **Pie Chart**: Sales by Ship Mode
5. **Filters**: Region, Category, Sub-Category, Segment, Month

---

## 🔍 Insights
1. The West region recorded the highest sales overall.
2. Technology category outperformed others in total revenue.
3. Sales peaked in November and December due to holiday season demand.
4. The Standard Class shipping method accounted for the majority of sales.
5. Office Supplies sub-category 'Binders' and 'Paper' contributed significantly to total sales.
6. Consumer segment had the highest contribution among customer types.
